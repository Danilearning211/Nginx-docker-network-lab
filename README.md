# Nginx Docker Lab

A small home lab project to practice Docker, Nginx, DNS, and Linux firewall.

The goal is to run a simple website inside a Docker container and control access to it using DNS and firewall rules.

## Plan

* Set up a Docker network
* Run Nginx in a container
* Set up a custom DNS
* Configure the Linux firewall
* Test the whole setup
